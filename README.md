# 🏢 HRZ (v2.0) - Plataforma Corporativa Avançada

O Projeto HRZ representa uma evolução arquitetural focada em escalabilidade e performance. Em sua versão 2.0, o sistema foi refatorado para entregar uma experiência de usuário mais robusta, com gestão de dados otimizada e fluxos de trabalho corporativos mais eficientes.

## ⚡ Desenvolvimento Ágil e Inovação (Vibe Coding)

Construído utilizando metodologias ágeis e ferramentas de Inteligência Artificial para aceleração de código (Cursor), este projeto reflete a capacidade de iterar sobre produtos existentes, refatorando legados para stacks modernas sem perder o foco na entrega de valor e regra de negócio.

## 🛠️ Tecnologias e Arquitetura

A stack foi escolhida para garantir uma base sólida para integrações futuras e manutenção simplificada:

*   **Core:** Ecossistema React (Next.js/Vite) focado em componentização inteligente e renderização otimizada.
*   **Linguagem:** TypeScript para tipagem estática, garantindo um código seguro e escalável.
*   **Estilização e UI:** Tailwind CSS e shadcn/ui, garantindo uma interface profissional, limpa e padronizada.
*   **Gestão de Estado & Infra:** Preparado para consumo eficiente de APIs e integração com BaaS (como Supabase/Firebase).

## 🏗️ Como executar localmente

Siga os comandos abaixo no seu terminal para configurar e rodar o ambiente de desenvolvimento na sua máquina:

```bash
# 1. Clone o repositório
git clone [https://github.com/Allan14GDS/projeto-hrz.git](https://github.com/Allan14GDS/projeto-hrz.git)

# 2. Acesse a pasta do projeto
cd ProjetoHRZ-v2.0

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
